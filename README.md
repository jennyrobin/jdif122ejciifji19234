# Telegram-бот «Мафия»

Групповой бот для «Мафии» на Python и aiogram 3: лобби, тайная раздача ролей, ночные действия мафии/доктора/комиссара и дневное голосование. Администратор группы может настраивать количество ролей в лобби.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Установите Python 3.10+ и зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Укажите токен и запустите:

   ```bash
   export TELEGRAM_BOT_TOKEN="токен-от-BotFather"
   python bot.py
   ```

   В PowerShell: `$env:TELEGRAM_BOT_TOKEN="токен-от-BotFather"`.

4. Добавьте бота в групповой чат. Каждый участник должен открыть личный чат с ботом и нажать `/start`, чтобы получать роль и ночные действия.

## Команды в группе

- `/newgame` — создать лобби.
- `/join` — присоединиться.
- `/roles` — посмотреть текущий состав ролей.
- `/setrole <роль> <число>` — изменить число ролей; **только администратор группы**.
- `/startgame` — начать игру (минимум 4 игрока).
- `/status` — посмотреть фазу игры и участников.
- `/endgame` — завершить игру.

### Настройка ролей администратором

Настройки меняются только в лобби. Доступны роли `мафия`, `доктор`, `комиссар`, `мирный` (можно задать `0` для ролей, которые не нужны). Например:

```text
/setrole мафия 2
/setrole доктор 1
/setrole комиссар 1
```

При изменении количества мафии, доктора или комиссара количество мирных жителей пересчитывается автоматически, чтобы состав совпадал с количеством игроков. Минимум одна мафия обязательна. Чтобы задать число мирных жителей вручную, используйте `/setrole мирный <число>` — оно должно точно соответствовать числу оставшихся мест. `/roles` показывает итоговую конфигурацию. Без ручных изменений состав ролей выбирается автоматически исходя из числа игроков.

Ночью мафия выбирает цель, доктор может спасти одного игрока, а комиссар проверяет одного игрока. Днём все живые игроки голосуют за исключение. Игра завершается, когда вся мафия выбыла или мафия сравнялась числом с остальными.

> Состояние хранится в памяти процесса: при перезапуске бота текущая игра сбрасывается. Токен храните в переменной окружения и не публикуйте его.
